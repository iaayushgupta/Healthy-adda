# Healthy Adda Tracker

## Run locally
```bash
npm install
npm run dev
```

## Deploy on Vercel
1. Create a new GitHub repository.
2. Upload these files.
3. Go to Vercel → New Project → Import GitHub repository.
4. Framework should auto-detect as Vite.
5. Click Deploy.

Note: This MVP uses browser localStorage, so progress is saved per device/browser. It is not collaborative across multiple users yet. For WhatsApp group collaboration, use the "Copy for Google Sheets" button and paste into Google Sheets, or add Firebase later.
